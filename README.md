## Supplementary materials from user experience evaluation to automated course design

# Supplementary Materials

This repository contains the supplementary materials associated with the experimental study reported in the paper *From User Experience Evaluation to Automated Course Design: Identifying Effective UX, Gamification, and H5P Design Elements in Moodle*.

### 1. **Participant Documentation**
This section contains the documents used to guide participants during the experiment.
- **1. Proceso_Guia_Participantes_ES.docx**: Participant guide describing the general process of the experimental study.
- **2. Consentimiento_informado_ES.docx**: Informed consent document in Spanish.
- **3. Procedimiento_acceso_cursos_ES.docx**: Document explaining how participants accessed the Moodle-based experimental courses.

### 2. **Experimental Architecture and Research Focus**
This section includes the visual materials used to describe the architecture and scope of the study.
- **4. paperFocus.png**: Image illustrating the research focus within the validated architecture.
- **5. architecture.png**: Image showing the global experimental architecture and data flow adopted in the study.

### 3. **Scenario Design and Interface Prototyping**
This section contains images related to the design and prototyping of the instructional scenarios.
- **6. design_1.png**: First interface design prototype used in the study.
- **7. design_2.png**: Second interface design prototype used in the study.

### 4. **Emotion Detection Evidence**
This section includes visual evidence of the facial emotion recognition process.
- **8. user_emotions_.png**: Example image of detected emotional expressions during the experimental sessions.

### 5. **Affective Dashboards and Visualizations**
This section contains dashboards and visual summaries of emotional data.
- **9. dashboard_user.png**: General affective dashboard of user emotion data.
- **10. dashboard_user_.png**: Additional dashboard showing emotional data visualization.
- **10.1. dash_userE1_.png**: Dashboard corresponding to scenario E1.
- **10.2. dash_userE7_.png**: Dashboard corresponding to scenario E7.
- **10.3. dash_userE9_.png**: Dashboard corresponding to scenario E9.
- **10.4. dash_userE3_.png**: Dashboard corresponding to scenario E3.
- **17. affectiva_emotions_dashboard.html**: Interactive HTML dashboard for exploring the emotion detection data.

### 6. **Usability and Comparative Results**
This section includes the quantitative visualizations used in the analysis of usability and scenario comparison.
- **11. E1_E3_E7_E9_overall_chart.png**: Comparative chart of average usability scores across scenarios E1, E3, E7, and E9.

### 7. **Qualitative Analysis**
This section contains the visual representation of the qualitative coding process.
- **12. axial_coding.png**: Image summarizing the axial coding process and categories used in the qualitative analysis.

### 8. **Emotion Data Files**
This section contains the anonymized emotion-related data generated during the experimental sessions.
- **13. emotions users.zip**: Compressed file containing the emotion data records used in the affective analysis.
- **14. emotions images.zip**: Compressed file containing the image captures associated with the emotion detection process during the experimental sessions.

These materials are provided to support transparency, reproducibility, and further inspection of the experimental process and results.
